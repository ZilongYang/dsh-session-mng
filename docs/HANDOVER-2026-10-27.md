### 0.1.1 列表逻辑（不要改坏）

- `computeView`：过滤 → 排序 → 分组 → 折叠 → 每组分页 → `visibleRows`；纯函数。
- 默认 `>100` 折叠；每工作区 50 条；`loadMore` 只改 `limits`，不改可见集。
- `viewKey` 变化（tab/工作区/搜索/展开集合/刷新）后 `selected = selected ∩ visibleIdSet`。
- 行 checkbox 的 `onSelect` 与工作区头 `onToggle` 必须分开；曾因此误折叠工作区。
- sticky 使用 `--dsw-alias-bg-layer-2`（与设置面板一致），不要改回 `bg-base` 黑色。

### P1 — 0.2.0：Host 侧 overview + 分页 sessions（主任务）

目标：真正支撑 **1000–10000 条会话**，不再首屏拉全量 state。0.1.1 只是客户端折叠/分页，state payload 仍是全量（202 条约 103 KB；10000 条约 5 MB）。

建议（实现前先写 `docs/PLAN-2026-10-28.md` 并让子龙批准）：

1. **`GET /session-mng/api/overview`**
   - 只返回 `workspaces[]`（id/title/path/status/sessionIds.length/archivedCount/总大小）+ `totals` + `capabilities` + `orphans`。
   - 计数优先用 `workspaceRegistry` 的内存 `sessionIds` / archived set；不要为计数读全部标题或日志。
   - 未分组会话数量：需要一次 header 扫描；做成懒加载 + 短 TTL 缓存，不阻塞首屏。
2. **`GET /session-mng/api/sessions?workspaceId=&tab=&offset=&limit=&query=&sort=`**
   - 只对当前页 id 做 `readTitleSnapshots` / `stat`；返回 `rows/total/offset/limit/hasMore`。
   - 已归档：用 `archivedSessionIds` 过滤 workspace 账本；不要扫全量日志。
   - 排序必须在 host 完成，保证分页稳定。
3. **全局搜索**
   - 先只读验证 `sessionController.search` / `sessionQuery.searchSessions` 是否覆盖标题；不覆盖就限制为“当前工作区/已加载页标题搜索”，内容搜索走宿主索引。
   - 搜索结果返回 id 列表后再按页补标题/大小，避免全量读标题。
4. **Client**
   - `overview` 首屏 → 默认折叠；展开工作区时请求第一页；`加载更多` 请求下一页；缓存每工作区页。
   - 保持 0.1.1 的 sticky、选择裁剪、搜索自动展开、视觉规范。
   - 选择语义：优先保留“可见集”语义；跨页选择需要明确“已加载页”边界，避免隐藏页误操作。
5. **兼容**
   - 保留 `GET /state` 给 0.1.x 客户端；Host 同时提供新旧接口，客户端 feature-detect.
   - 版本 0.2.0；升级 README/CHANGELOG/ROADMAP；新增 `docs/RELEASE-CHECKLIST-0.2.0.md`.
6. **验收**
   - 合成 10k 会话数据：首屏 overview 不带 session rows；单页 ≤50 行；不触发全量 `sessionController.list`。
   - 现有 26 个测试 + 新增 overview/page/search/分页/空态/归档/未分组测试。
   - 实机只读验证 202 条真实数据，再用手动合成数据验证 1000/10000；写操作仍只用一次性测试会话。

## 5. 环境与坑

- DSH `0.2.1-rc.2`；Desktop `desktop` profile **由应用独占**，不要用 `dsh plugin --profile desktop …` 管理；用应用内插件管理器或 `plugin_manager`。
- Client 服务只能 `ctx.get('uiWorkspace')`；直接 `ctx.uiWorkspace` 在未 inject 时会抛错，且被 try/catch 吞掉会导致“恢复并打开”消失。
- 移动依赖 workspace registry 内部缓存 seam；已做特性检测和回滚，升级 DSH 先跑测试 + 实机验收。
- 移动/删除只支持本地 JSONL；live 会话拒绝移动/删除，重启后重试。
- 测试/截图只用一次性测试会话或 `/Users/demo/...` + `session-demo-*` 假数据；不要提交真实标题/路径/会话 id。
- 公开计划是脱敏版；逐字原文在 `private/raw-plans/`（gitignore，不进 npm）。
- 0.1.1 的 npm tarball 是在最终文档回填前打的，包内 checklist 可能显示 pending；功能/README 无影响。不值得为这个单独发 0.1.2。
- GitHub tag `v0.1.1` 指向 `1b6a07f`；之后只有文档提交 `7e1b457`，代码一致。
